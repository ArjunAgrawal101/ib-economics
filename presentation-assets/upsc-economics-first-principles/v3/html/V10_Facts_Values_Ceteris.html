Positive statement: what is
Testable with evidence
“If bus fares rise, the number of daily bus passengers will fall.”
Normative statement: what ought to be
Value judgement
“Bus fares should be kept low so that everyone can afford to travel.”
Signal words such as should, ought and fair usually mark a normative claim.

# UPSC CSE Economics, Section I: Economics from First Principles

Diagram assets for the Gamma deck "Economics from First Principles: Scarcity, Choice, Production and Markets" (Arjun Agrawal | UPSC CSE Economics). Do not delete: the Gamma deck links to these files.

- `png/` slide-ready diagrams (2x PNG, transparent background)
- `svg/` vector sources of the same diagrams
- `source/` generator scripts: `build_graphs.py` (PPC, demand and supply), `build_flows.py` (concept and circular-flow diagrams), `render.py` (headless Chromium, Inter and Lora fonts)
- `brand/AA_Logo_trimmed_transparent.png` the attached logo with white margin trimmed and white background made transparent (mark unchanged)

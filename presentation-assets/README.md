# Presentation assets

Image assets for Arjun Agrawal IB DP Economics Gamma decks. Hosted here so Gamma can load them by URL.
This folder is not part of the website build.

- `exchange-rates/png/` slide-ready diagrams (2x PNG)
- `exchange-rates/svg/` editable vector diagrams
- `exchange-rates/source/` generator scripts and infographic HTML
- `exchange-rates/brand/` logo prepared for slide footers (white margin trimmed, white background made transparent; mark unchanged)
- `market-failure-externalities-cpr/` diagrams and infographics for the Market Failure (externalities and common pool resources) deck; `brand/MF_00_Logo_Watermark.png` is the same trimmed transparent logo with its alpha reduced to 25% for use as a slide watermark (mark unchanged)
- `upsc-economics-first-principles/` diagrams for the UPSC CSE Economics Section I deck (scarcity, PPC, circular flow, demand and supply); see its README

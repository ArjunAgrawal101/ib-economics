What it helps learners do

  • See the whole of a topic before its parts
  • Follow the connections between topics
  • Rebuild a map from memory

The thinking behind it

Maps are built to be connected: a topic map leads into a synthesis map that joins it to another part of the course, which is where evaluation usually comes from.
